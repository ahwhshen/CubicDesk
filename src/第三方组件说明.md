# 随附媒体组件

Cubic Desk 随附 FFmpeg 与 FFprobe，用于读取视频信息及转换为摆件可用的 MJPEG AVI。程序通过独立进程调用它们，没有修改这些二进制文件，也没有把它们链接进主程序。

- 构建：FFmpeg 9.0.2-full_build-www.gyan.dev，Windows x64 静态构建。
- 构建提供方：[Gyan FFmpeg Builds](https://www.gyan.dev/ffmpeg/builds/)。
- FFmpeg 对应源代码：[946fcce07b](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b)。
- 组件许可：GNU GPL v3。完整许可原文在 `tools/ffmpeg/LICENSE`。
- 构建方原始声明、构建配置和源代码入口在 `tools/ffmpeg/README.txt`。
- 文件版本、来源、大小和 SHA-256 在 `tools/ffmpeg/component.json`。

FFmpeg 的版权属于 FFmpeg 开发者及各组件作者。本说明不替代随附的原始许可证。相关许可证和构建声明应随组件一起保留。

正常使用无需单独安装或配置。请保留完整的 `tools/ffmpeg` 目录；主程序不会从系统 PATH 或旧的个人路径调用其他 FFmpeg。
