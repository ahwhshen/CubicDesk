# Cubic Desk v1.5.1

> 用途：说明 v1.5.1 下载版本、安装步骤与验证边界。

首个 GitHub 公开版本，面向兼容 Cubic 后台协议的 HoloCubic 摆件，提供 Windows 原生管理界面。

## 下载与安装

- **Windows 打包版**：下载 `CubicDesk-v1.5.1-windows-x64.zip`，完整解压后运行 `CubicDesk/CubicDesk.exe`。已内置 FFmpeg / FFprobe，无需另装 Node.js 或 .NET SDK。
- **源码版**：下载 `CubicDesk-v1.5.1-source.zip` 或克隆仓库，在项目根目录运行 `.\build.ps1`。使用系统 .NET Framework 编译器，兼容 C# 5。源码不含 FFmpeg 二进制；需要转码／重新打包时，从 Windows 包复制完整 `tools/ffmpeg` 目录。
- **文件校验**：使用 `SHA256SUMS.txt` 核对两个 ZIP。

支持 Windows 10 1809+ / Windows 11 x64、Windows PowerShell 5.1、.NET Framework 4.8。升级请彻底退出旧版，保留原来的个人 `data` 文件夹。

## 功能

- 扫描 clocteck-cubic 前缀热点，连接后配置摆件的目标 Wi-Fi；默认支持本机移动热点。
- 应用、资源、设备设置与独立的电脑端依赖清单。
- Windows 系统媒体会话桥接，多播放器歌名、进度、封面与播放控制。
- QQ 音乐 / 网易云在线歌词匹配，缺少系统封面时补取专辑图，失败后自动重试。
- 托盘后台运行，以及关闭 / 前端 / 仅后端三档开机启动。
- 白色液态玻璃界面。

## 验证与边界

已验证源码编译、实机管理连接、热点扫描、QQ 音乐封面／歌词传输及网易云公开接口。完整 Wi-Fi 切换恢复、应用商店安装和其他播放器实播需按实际设备环境验证。部分应用专有复杂设置尚未适配。在线服务可能受接口与网络变化影响。
