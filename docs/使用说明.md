# Cubic Desk · 摆件管理

一个原生 Windows 桌面应用，通过局域网 HTTP 接口直接管理 Cubic 摆件。界面不嵌入网页，不需要浏览器、Node.js 或 .NET SDK。

当前版本为 **1.5.1**，开机启动支持关闭、前端和仅后端；内置视频转码组件，在线歌词支持 QQ 音乐和网易云音乐，托盘菜单采用浅色圆角样式。保留应用商店与独立的依赖清单。界面保持珍珠白主色、半透明圆角玻璃面板、随鼠标移动的柔和反光，以及从内向外逐层减弱的白色光晕。窗口外缘和卡片边缘都使用白色光晕。可拖动顶部标题区域移动窗口，通过右下角标记调整大小；顶部提供最小化、最大化/还原和关闭。

## 运行

双击 `outputs/CubicDesk/CubicDesk.exe`。请保留同文件夹中的 `Theme.xaml`、`dependencies.json`、PowerShell 脚本与 `.config` 文件。可整体移动 `CubicDesk` 文件夹，运行时配置与备份位于其中的 `data` 文件夹。

适用环境：Windows 10 1809 或更高版本、Windows 11，x64，系统自带 Windows PowerShell 5.1 与 .NET Framework 4.8。开发环境已完成编译、启动和实机连接验证；完整配网切换流程仍需按实际网卡环境验证。

## 后台与开机启动

整个应用以当前 Windows 用户的后台常驻程序运行，管理窗口关闭后，设备状态检查、正在执行的操作、音乐桥接、封面与歌词继续工作。后台保留系统托盘图标，双击图标或再次打开 CubicDesk.exe 可恢复原窗口，不会重复启动一份程序或争用桥接端口。托盘右键菜单提供“彻底退出”，用于结束整个后台及配套工作进程。

在“后台与启动”选择开机启动方式，再点击保存：**关闭**不随登录启动；**前端**启动并打开管理窗口；**仅后端**静默在托盘运行。两种启动方式都会运行后台并保留桥接偏好。此设置只影响当前用户，无需管理员权限；托盘菜单也提供同样的三档选择。旧版已开启静默启动的设置会识别为“仅后端”。移动便携文件夹后需要在新位置重新保存。

后台会继续检查已记住的摆件地址；首次连接失败时每约 15 秒重试一次，已连接设备每约 3 秒刷新状态。音乐桥接可在摆件尚未上线时先启动，等待网络恢复。后台不会自动改热点、密码、防火墙或摆件配置。睡眠、关机或注销 Windows 会中断运行，重新登录后可由开机启动恢复。

实现使用 Windows 当前用户的 [Run 登录启动项](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)，以当前登录用户身份常驻，能够访问该用户的音乐媒体会话。

## 应用图标

应用管理、应用商店、首页、设备设置中的开机应用、应用配置、依赖安装和 Windows 音乐使用统一的应用图标。优先通过摆件的网上应用中心读取 `icon_url`；读取失败时使用已有云端缓存，再读取摆件的本地图标，最后使用随附图标或功能占位图。图片异步读取，不影响操作；“更新应用图标”可重新尝试云端目录和图片，并显示实际读取结果。应用中心连接异常不代表摆件离线。

## 日常使用

- **发现设备**：点击“扫描摆件热点”，通过 Windows 无线网卡查找名称以 `clocteck-cubic` 开头的 Wi-Fi（含后缀），按信号强度排序；仅扫描不会切换网络。右侧“摆件的联网目标”默认选择“本机移动热点（推荐）”，自动显示本机热点名称并读取实际密码；也可以切换“其他 Wi-Fi”后填写名称和密码，再点击搜索结果的“连接并配网”。程序临时连接摆件热点，确认设备身份后通过原生配网接口提交目标网络；无论成功、失败或取消，都会尝试恢复电脑原 Wi-Fi，并重新查找摆件的新地址。只有核对到目标 Wi-Fi、有效局域网地址和摆件身份后才报告配网完成。已配网设备可展开“已联网摆件：按地址连接”。
- **配网说明**：摆件热点通常开放；如显示加密，需另填“摆件热点密码”，与右侧目标 Wi-Fi 密码分开。自动连接支持开放热点及 WPA2-Personal/AES；其他加密方式请先在 Windows 中连接后按地址管理。目标网络建议 2.4 GHz，无需网页登录。电脑原网络若没有已保存的连接配置，可能需要手动恢复。选择本机热点会在配网前准备热点，并在恢复电脑网络后重新开启。Windows 若拒绝读取 WLAN，需要用户自行检查相应访问权限。取消不会撤回已经发给摆件的连接命令。两种密码只在本次操作内存中使用，不写入配置或日志；只记住目标 Wi-Fi 名称。
- **网络与热点**：读取、启停电脑移动热点；选择热点的上网来源（例如以太网）；本机热点是摆件连接的目标，可直接点击“让摆件连接本机热点”，未配网时会转到热点配网流程；修改热点名称和密码；固定使用 2.4 GHz。留空密码可保留原密码。修改热点时可同时为当前摆件保存新 Wi-Fi 信息。
- **摆件配网**：扫描摆件附近的 Wi-Fi，手动连接其他 Wi-Fi，或直接为摆件设置本机热点。连接后会尝试确认网络与设备地址；若地址改变，可以重新搜索。
- **应用管理**：显示摆件实际安装的应用，直接启动、重新打开或返回启动器。“配置”把简单 JSON、`config.lua` 和 `settings.lua` 字段转成原生表单；Windows 音乐进入独立的 SMTC 配置区域。复杂 Lua 表达式、数组与没有配置文件的应用不会被强行改写。
- **资源管理**：按类别浏览、下载、上传与删除图片、GIF、视频、音乐、LRC 和游戏 ROM。覆盖文件前询问并备份；删除会二次确认。图片自动适配 320 × 240，保留透明通道。游戏文件上传到已存在的对应平台目录。
- **设备设置**：亮度、时区、语言、天气地址、开机应用、配网热点保留、固件检查与手动更新。保存前读取并合并最新设置，保留其他字段。配置文件自动备份到 `data/backups`。

## 依赖安装：第三方应用清单

“依赖安装”用于统计和提供界面。它将摆件应用与电脑端运行环境、驱动或桥接程序关联，提供下载页、作者说明、版本要求和配置步骤。点击链接会打开浏览器，由用户自行下载、安装和配置；本页不会运行第三方安装程序。

- 通过下拉框按应用查看，也可以只看当前摆件已安装的软件，或找出尚未登记依赖的软件；搜索支持软件名称、依赖名称和用途。
- 同一依赖可关联多个应用，统计时去重。每项状态为“未确认”“已准备（人工确认）”或“暂不需要”。状态是用户记录，不代表系统自动检测通过；必需依赖标记“暂不需要”仍算未确认准备。
- “登记依赖”可维护名称、下载链接、说明链接、用途、版本与可选要求。“编辑信息”会更新共用依赖的说明；需要给多个应用关联同一组件时使用相同依赖标识。
- “未登记依赖”与“确认无需外部依赖”分开展示，缺少资料时不会推断为无需依赖。手动确认无依赖前请核对作者说明。
- 支持 JSON 清单导入、合并和导出。导入前整体校验，下载与说明链接仅支持不含账号密码的 HTTP/HTTPS。导入不接受别人的安装确认状态。已存在的本地清单在修改前备份到 `data/dependency-backups`，并保留未识别的记录字段。
- 定义保存在 `data/dependency-catalog.json`，本机人工状态单独保存在 `data/dependency-status.json`。导出只含定义与应用关联，不含本机状态。

预置记录包括电脑性能监控的 AIDA64 RemoteSensor、PC Mirror 的 Python 与电脑发送端，以及 Windows 音乐所需的桥接。PC Mirror 是清单示例，不代表当前摆件已安装。无法确认的第三方 SMTC 桥接下载地址保留“待补充”，已有随附桥接可在“本机工具”中使用。

预置资料依据 [电脑性能监控作者说明](https://github.com/clocteck/holocubic-apps/tree/main/holo_pc_monitor)、[PC Mirror 作者说明](https://github.com/clocteck/holocubic-apps/tree/main/pc_mirror)、[电脑投屏发送端](https://github.com/clocteck/desktop-mirror)、[AIDA64 官方下载页](https://www.aida64.com/downloads)和 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/)。实际许可、兼容版本和安装步骤以各作者最新说明为准。

## 应用商店与依赖提示

连接摆件后，进入“应用商店”，点击“刷新设备商店”。目录通过摆件自己的后台读取，支持搜索、已安装过滤、依赖信息过滤、作者说明，以及导入作者提供的目录 JSON。远程读取失败时会显示实际错误并保留缓存或当前已安装清单。

安装新应用前会显示关联依赖和人工准备状态，可选择“先查看依赖”跳转到该应用的清单，也可继续安装设备端应用。默认在设备报告安装成功后再次打开依赖页面。设备应用安装与电脑端依赖安装是两个独立步骤。

应用已安装时，本入口禁用重复安装，避免覆盖现有配置。未提供有效安装清单 URL 的条目无法安装；也可以输入作者提供的应用标识和 manifest 地址。提交后等待设备任务结果及已安装清单确认，超时或失败会如实提示。开发阶段未完成应用安装／卸载的端到端验证；曾遇到远程商店目录返回 `upstream open failed: ESP_ERR_HTTP_CONNECT`，联网安装完整流程尚未完成实机验证。

只有商店条目明确声明的 `pc_dependencies` 或 `desktop_dependencies` 才会自动加入电脑端清单；普通 `dependencies` 可能属于设备端，不会混用。作者未声明时可由用户维护，手工维护的关联优先于后续商店刷新。离线也可以维护依赖清单。

## 本机工具：Windows 音乐 / SMTC

SMTC 媒体会话能力来自 Windows。“安装本地组件”安装的是 Cubic Desk 随附的桥接脚本，不需要额外下载 Node.js 模块。

1. 连接摆件，进入“本机工具”。
2. 点击“安装本地组件”。如果已经安装，可以直接下一步。
3. 检查桥接端口，默认 `17865`；电脑采样间隔默认 `800` 毫秒。
4. 点击“启动桥接”。在音乐软件播放歌曲，使用“刷新媒体会话”选择播放器，或保留自动选择。
5. 检查“摆件访问的电脑地址”。应用会填写通向当前摆件的本机地址；电脑热点通常是 `192.168.137.1`。
6. 点击“写入摆件并打开 Windows 音乐”。应用备份原配置，写入电脑地址、端口、轮询和超时，使用摆件自己的配置接口立即应用。
7. 查看“摆件最近请求”确认连接。如果没有请求，点击“允许当前摆件访问桥接”，由 Windows 请求管理员授权，为指定摆件、程序和端口创建放行规则。

桥接提供标题、艺术家、专辑、进度、可用封面、上一首、下一首、播放与暂停。只接受配对摆件和本机的连接。关闭管理窗口会收起到系统托盘，后台桥接继续运行；只有“彻底退出程序”才停止桥接与它启动的工作进程。“下次打开时自动启动桥接”控制桥接启动偏好，Windows 开机启动在“后台与启动”单独设置。

音乐软件必须向 Windows 提供系统媒体会话。没有会话时，应用会显示等待状态。封面是否存在也由播放器提供。可以导入本地 LRC 并绑定歌曲标题；歌词保存在 `data/lyrics`，切换到其他歌曲时不会混用。当前保存最近一次导入的歌曲绑定；匹配当前歌曲的本地导入歌词优先于在线歌词。

### 多播放器与在线歌词

Windows 音乐桥接读取系统媒体会话，可同步 QQ 音乐、网易云音乐以及其他支持该接口的播放器的歌名、歌手、封面、进度及播放控制。播放器需要提供系统媒体会话；是否提供封面、可用控制按钮由播放器决定。播放后可点击“刷新媒体会话”，选择播放器再“保存偏好”；也可使用 Windows 当前会话自动选择。

在“本机工具 → 同步歌词”开启“自动匹配在线歌词”，选择来源：

- **自动跟随播放器**：识别 QQ 音乐与网易云音乐的媒体会话，使用对应歌词来源。
- **QQ 音乐**或**网易云音乐**：手动指定来源，也可为其他播放器匹配这两个来源的歌词。

开启后，会向选定服务查询当前歌曲名称和歌手，并用歌名、歌手和时长核对版本。本地 LRC 优先使用。切歌或更换来源时清除旧匹配，后台重新查询；本机缓存最近 20 次匹配，彻底退出后清空。不读取音乐账号凭据，不下载歌曲。没有匹配结果或服务不可用时显示实际原因，可重试、切换来源或导入 LRC。歌词可用性取决于对应服务；接口可能变化。

QQ 音乐的实播封面和歌词已验证；网易云的公开搜索与同步歌词接口已验证，尚未使用网易云播放器完成实播验证。其他播放器需要实际提供媒体会话，未逐个验证。

## 内置视频转码

FFmpeg 与 FFprobe 已随便携包放在 `tools/ffmpeg` 中。程序自动使用内置版本，不读取旧的个人路径或系统 PATH，本机工具页不再显示路径选择、检测和保存设置。请保留整个组件目录，相关许可和来源见“第三方组件说明.md”。

视频最长 10 分钟，输入与转换结果最大 200 MB；自动转为 320 × 240、20 fps 的无声 MJPEG AVI 后上传。GIF 直接上传，最大 50 MB。随附的两个组件解压后共约 434 MiB，便携包因此会增大；正常转码无需另外下载或配置。

## 当前边界

摆件固件 `1.203` 没有新版服务启停接口，应用因此禁用服务启动、停止按钮；固件 `1.204` 或更高版本才显示可操作状态。固件更新需要主动检查和确认，开发验证没有更新固件。

本版覆盖通用后台功能、应用商店新应用安装入口、依赖清单和可安全解析的配置字段。部分插件的专用复杂设置尚未逐个适配，继续迁移需要分别对接字段、接口和保存逻辑。SMTC 已提供专门的原生配置界面；其他应用若没有支持的配置文件，会明确提示。当前商店入口不执行更新、卸载或启动器替换。

热点启动、重命名和改密码会影响连接该热点的设备。配网信息保存在摆件，电脑热点密码仅在运行内存中用于相关操作，不写入应用日志或偏好文件。

## 源码与构建

源码位于项目根目录的 `src`。在 Windows PowerShell 或 PowerShell 中运行根目录的 `build.ps1`，使用系统自带的 .NET Framework C# 编译器生成 `outputs/CubicDesk`。代码兼容 C# 5。从源码重新构建时，视频转码还需保留便携包中的 tools/ffmpeg 文件夹；build.ps1 不自动下载第三方二进制。

运行 `CubicDesk.exe --self-test --device 192.168.137.7` 可执行诊断。结果写入 `data/diagnostics.json`。诊断包括地址验证、设备身份识别、Lua 字符转义与非目标字段保留、LRC 协议、热点只读查询、图片适配、视频转码、SMTC 工作进程与 HTTP 协议、实机状态与配置读取，以及五组依赖清单检查（缺失资料、共用与持久化、导入状态隔离、无效清单拒绝、手动维护优先）。清单检查使用临时目录，不更改用户的人工状态。视频转码检查使用内置组件。附加 --music-live 可检查实际 QQ 音乐封面及在线歌词；附加 --netease-live 可检查网易云公开歌词接口；附加 --background-live 会只读检查当前用户是否已登记本程序的前端或仅后端启动项，不会自动创建启动项。诊断不修改摆件设置、不安装固件、不改变防火墙规则。

设备接口依据当前摆件的实际后台与插件协议实现。Windows 系统接口参考：

- [Windows 网络共享接口](https://learn.microsoft.com/en-us/uwp/api/windows.networking.networkoperators.networkoperatortetheringmanager)
- [Windows 系统媒体会话接口](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager)
- [FFmpeg 官方文档](https://ffmpeg.org/documentation.html)

## 封面与歌词恢复

在线歌词和在线封面查询失败后会自动重试，间隔从约 5 秒逐步延长，最长约 60 秒。播放器未提供系统媒体封面时，可在“本机工具”启用“自动补取在线专辑封面”，按歌曲、歌手和时长匹配 QQ 音乐或网易云专辑图；系统媒体封面优先。切换歌曲会取消旧请求，封面内容更新会通知摆件重新读取。最近 20 首歌词和封面在本次运行中缓存。在线请求使用 Windows 网络代理设置，摆件局域网请求仍绕过系统代理。
